# Echo Landing Page

Premium modern landing page for **Echo**, an anonymous multilingual peer-support platform created by team **Null Pointers**.

## Project Structure

```text
.
├── index.html
├── assets
│   ├── css
│   │   └── styles.css
│   └── js
│       └── script.js
├── README.md
├── .gitignore
└── package.json
```

## Run Locally

This is a static site. You can open `index.html` directly, or serve it locally:

```bash
python -m http.server 4173
```

Then open:

```text
http://127.0.0.1:4173
```

## Deploy

For GitHub Pages, push this repository and deploy from the root folder on your main branch.
